# Coding Conventions

**Analysis Date:** 2026-08-07

## Code Style
- Follows PSR-12 and standard Laravel conventions.
- Format enforcement tool available: Laravel Pint (`laravel/pint` ^1.27).

## Naming Patterns
- **Controllers**: PascalCase, ending in `Controller` (e.g., `UserController`).
- **Models**: Singular PascalCase (e.g., `User`).
- **Database Tables**: Plural snake_case (e.g., `users`).
- **Variables & Methods**: camelCase.

## Error Handling
- Handled globally by the Laravel exception handler.
